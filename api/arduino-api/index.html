Monitoramento Meteorológico Inteligente

Sistema IoT avançado para coleta e análise de dados meteorológicos urbanos em tempo real. Utilizando sensores Arduino BME280 para temperatura e umidade, com interface web moderna e APIs RESTful para integração com outros sistemas.

Dados Precisos

Sensores BME280 calibrados para medições precisas de temperatura e umidade relativa do ar.

Tempo Real

Atualização automática dos dados a cada 5 segundos com visualização em gráficos dinâmicos.

API RESTful

Endpoints JSON para integração com outros sistemas e aplicações de terceiros.

Especificações Técnicas

Hardware

  • ESP32 DEV KIT V1
  • Sensor BME280 (Temperatura, Umidade e Pressão Atmosférica)
  • Conexão Serial USB
  • Alimentação 5V

Software

  • Node.js + Express API
  • Interface Web Responsiva
  • Gráficos em Tempo Real
  • Previsão do Tempo Integrada

Sobre

CIDA: tecnologia para compreender o ambiente urbano

O CIDA nasce com a missão de transformar dados ambientais em informação útil para a comunidade, universidades e profissionais que desejam analisar como o clima se comporta em tempo real.

Através de sensores conectados, coleta de dados e uma interface moderna, o projeto oferece um panorama claro sobre temperatura, umidade e condições do ambiente, apoiando decisões mais inteligentes e sustentáveis.

Monitoramento contínuo

Coleta automática de dados com atualização em tempo real para análise imediata.

Dados acessíveis

Visualização moderna e API pronta para integração com outros sistemas e aplicações.

Sustentabilidade

Apoio à tomada de decisão com soluções tecnológicas para ambientes urbanos mais inteligentes.
