Monitoramento Meteorológico Inteligente

Sistema IoT avançado para coleta e análise de dados meteorológicos urbanos em tempo real. Utilizando sensores Arduino BME280 para temperatura e umidade, com interface web moderna e APIs RESTful para integração com outros sistemas.

Dados Precisos

Sensores BME280 calibrados para medições precisas de temperatura e umidade relativa do ar.

Tempo Real

Atualização automática dos dados a cada 5 segundos com visualização em gráficos dinâmicos.

API RESTful

Endpoints JSON para integração com outros sistemas e aplicações de terceiros.

Especificações Técnicas

Hardware

  • ESP32 DEV KIT V1
  • Sensor BME280 (Temperatura, Umidade e Pressão Atmosférica)
  • Conexão Serial USB
  • Alimentação 5V

Software

  • Node.js + Express API
  • Interface Web Responsiva
  • Gráficos em Tempo Real
  • Previsão do Tempo Integrada
